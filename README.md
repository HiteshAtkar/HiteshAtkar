## About Me

I'm a **Generative AI Engineer** who takes LLM products from idea to production: multi-agent platforms, RAG pipelines, hybrid search engines and document-intelligence systems that run for real clients.

<table>
<tr>
<td width="50%" valign="top">

#### Agentic AI
Multi-agent workflows (ReAct, Reflexion, Plan-and-Execute) with tool calling and custom **MCP** servers.

#### RAG & Search
Hybrid retrieval (BM25 + vectors), re-ranking, knowledge graphs and multimodal RAG.

</td>
<td width="50%" valign="top">

#### Document AI
Vision-LLM extraction, OCR and schema-validated structured JSON output.

#### LLMOps
Evaluation, guardrails, tracing with LangSmith, CI/CD and cloud deployment on AWS.

</td>
</tr>
</table>
